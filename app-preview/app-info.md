## 四、描述（Description）

PortWatcher 是一只住在菜单栏里的端口监视猫。

点开顶栏图标，本机所有 TCP / UDP 监听端口尽收眼底——哪个端口、哪个进程、PID 多少、谁启动的、吃了多少内存，一屏看清。

▸ 实时刷新
每 5 秒自动扫描，端口新增、关闭、进程重启即时提醒，内存波动一目了然。

▸ 自定义常用
把高频端口标星收藏，「常用」视图只看你关心的；备注业务名（如「我的网站」），再也不用猜 8080 是什么。

▸ 自启动识别
基于 launchd 识别登录项 / 后台服务，单独筛选；系统进程自动排除，只留你装的服务。

▸ 不止是看，还能管
展开端口即可查看监听地址、工作目录、可执行文件与完整命令；支持一键重启、强制停止（带确认）、在 Finder 显示、复制命令、直接拉取进程最近日志。

▸ Web 服务秒开
检测到 Dev Server / Web 服务时，一键在浏览器打开 http://127.0.0.1:端口。

▸ 系统资源同屏
内存与磁盘占用常驻面板顶部，异常占用一眼发现。

原生 Swift 编写，轻量常驻，不收集任何数据。
