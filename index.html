A tiny port monitor
for your menu bar

PortWatcher watches your macOS listening ports, processes, and system resources in real time — all from a single popover. Native SwiftUI, zero dependencies.

Take a look

The menu-bar popover — live.

What it does

Everything lives in the status bar. No windows, no clutter.

🔢

Live port count

The menu-bar icon shows how many ports are listening right now.

📊

System resources

Memory and disk usage at a glance, colored when they run high.

📋

Full port list

Every TCP/UDP port with process, PID, user, address, and launch source.

⚡

Change feed

Auto-diffed banner: added / restarted / closed, with NEW & memory tags.

🔎

Filter & search

All / Favorites / Local / Auto-launch, plus free-text search.

🛠️

Restart / stop

Kick a launchd job or kill a process, with a confirm dialog and history log.

📝

Logs on demand

One click pulls the real process logs via log show.

🌐

English / 中文

Follows your system language, with a manual switch in Settings.

🚀

Login item

Start at login — just drop the app in /Applications.

Private by design

PortWatcher reads only local system state. It makes no network connections and collects zero data — nothing ever leaves your Mac. The only outbound action is opening 127.0.0.1:<port> in your browser when you ask it to.
